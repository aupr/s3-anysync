# Contributing to s3-anysync

Contributions are welcome: bug reports, fixes, docs, and new features.

## Getting started

1. Fork the repository and clone your fork.
2. Build and run the tests as described in the [README](README.md) (`Build`, `Tests` and `Development` sections).
3. Create a branch for your change.

## Before you open a pull request

- Keep changes focused; one topic per pull request.
- Add or update tests for behaviour you change.
- Run the Go tests (and the frontend tests if you touched `frontend/`) and make sure they pass.
- Update the README or docs if user-visible behaviour changes.
- Windows-only code is currently untested on real Windows; reports and fixes there are especially helpful.

## Reporting bugs and ideas

Open an issue with what you did, what you expected, what happened, your OS, and the app version. Check the "Known limitations" section of the README first.

## Security

Please do not post security problems or credentials in public issues. Contact the maintainer privately instead.
